# Deadly Bouncy Balls (C++ / SFML)

A fast-paced 2D arcade-style mini game where the player dodges and shoots bouncing balls that move, collide, and split into smaller, faster balls over time. 

## Design Goals
- Develop and ship a complete, playable mini game prototype
- Apply core game development concepts, including real-time game loops, physics simulation, entity interactions, game states management, and UI navigation
- Gain hands-on experience with SFML and modern game development

## Features
- Gameplay: Ball physics, collision detection, splitting mechanics, shooting, and aiming
- Dynamic Difficulty: Randomized ball properties and blinking warnings before splitting
- Game States & UI: Start, gameplay, and game-over screens with interactive buttons, pause menus, and instructions
- Architecture: Modular systems for combat, shooting, collision, aiming, entities, physics, and UI
